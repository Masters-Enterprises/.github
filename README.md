# Masters Enterprises GitHub profile

This public repository contains organization-level GitHub profile material for Masters Enterprises.

- `profile/README.md` is rendered on the Masters Enterprises organization overview.
- `profile/assets/` contains the public vector artwork used by that profile.

Organization-wide community-health files are intentionally not defined here at present, so this repository does not impose default contribution, issue, pull-request, or security templates on other Masters Enterprises repositories.

For the group website, visit [masters-enterprises.com](https://masters-enterprises.com).
